## 4. Clases Tailwind identificables

Estas son las clases visibles y su función:

| Clase                | Función                                                        |
| -------------------- | -------------------------------------------------------------- |
| `hidden`             | Oculta el elemento por defecto.                                |
| `flex`               | Activa el diseño Flexbox.                                      |
| `flex-1`             | Permite que el elemento crezca para ocupar espacio disponible. |
| `items-center`       | Alinea los elementos en el eje transversal.                    |
| `gap-2`              | Establece separación entre elementos de `0.5rem`.              |
| `gap-7`              | Establece separación de `1.75rem`.                             |
| `text-sm`            | Tamaño de texto pequeño.                                       |
| `font-bold`          | Peso de fuente en negrita.                                     |
| `font-semibold`      | Peso de fuente seminegrita.                                    |
| `relative`           | Establece posicionamiento relativo.                            |
| `absolute`           | Establece posicionamiento absoluto.                            |
| `left-4`             | Desplazamiento izquierdo de `1rem`.                            |
| `top-1/2`            | Posición superior del 50 %.                                    |
| `-translate-y-1/2`   | Desplaza el elemento hacia arriba el 50 % de su propia altura. |
| `size-5`             | Ancho y alto de `1.25rem`.                                     |
| `h-12`               | Altura de `3rem`.                                              |
| `w-full`             | Ancho del 100 %.                                               |
| `rounded-full`       | Radio de borde completamente redondeado.                       |
| `border`             | Aplica un borde.                                               |
| `grid`               | Activa CSS Grid.                                               |
| `place-items-center` | Centra los elementos dentro de sus celdas de Grid.             |
| `size-10`            | Ancho y alto de `2.5rem`.                                      |
| `ml-auto`            | Aplica margen izquierdo automático.                            |
| `md:block`           | En el breakpoint `md` y superiores, aplica `display: block`.   |
| `lg:flex`            | En el breakpoint `lg` y superiores, aplica `display: flex`.    |

Los breakpoints exactos dependen de la configuración de Tailwind del proyecto. En una configuración predeterminada moderna, `md` comienza en 48 rem y `lg` en 64 rem.
